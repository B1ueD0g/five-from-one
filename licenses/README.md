# License and data provenance

- [MIT](../LICENSE) covers the original audit and rendering code in this repository.
- GSM8K question material and gold answers are from OpenAI's Grade School Math repository at commit `3101c7d5072418e28b9008a6636bde82a006892c`. The numeric artifacts use selected test records and generated completions. The replay TSVs wrap each selected question in the study's prompt template and add tape routing. The original MIT notice is preserved in this directory. [Upstream dataset and notice](https://github.com/openai/grade-school-math/tree/3101c7d5072418e28b9008a6636bde82a006892c) · [Local MIT notice](GSM8K-MIT.txt)
- `artifact/arc_labels.json` adapts the Allen Institute for AI's ARC-Challenge test set by retaining question IDs and answer keys and adding labels extracted from the study's completions and the registered order of the calls. Question texts and answer choices remain at the source. The extract carries the source dataset's CC BY-SA 4.0 terms insofar as they apply to its dataset-derived contents. [AI2 dataset card](https://huggingface.co/datasets/allenai/ai2_arc) · [CC BY-SA 4.0](ARC-CC-BY-SA-4.0.txt)
- The native application links against llama.cpp b12428. Its dependencies and the Qwen checkpoint are obtained from their maintainers under their own terms. [llama.cpp license](https://github.com/ggml-org/llama.cpp/blob/b12428/LICENSE) · [Qwen checkpoint license](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF/blob/main/LICENSE)
